# Daily desk packet

Copy to `outputs/prototypes/YYYY-MM-DD/desk/packet.md`.

## Run

| Field | Value |
|---|---|
| Date | YYYY-MM-DD |
| host |  |
| started_at_pt |  |
| outcome | pending |
| archive_bar | pending / pass / fail / override |
| caption_choice |  |
| drawing_choice |  |
| promotion_slug |  |
| post_url |  |

`outcome` allowed values: `pending`, `kill`, `ship`.

## Pulse

List 8-12 premises with controversy, clickbait, and New Yorker-fit notes.

## Risk kills

Premise and why it died.

## Survivors

The three premises shown to the operator.

## Captions

A-E plus grader table after `comic-ideation`.

## Archive bar

Three similar finals and the pass / fail / override decision.

## Choice

The operator's premise, caption, kill, or override, in their words.

## Renders

Two signed PNG paths and their sidecars. Do not overwrite.

## Outcome

`kill` with reason, or `ship` with slug, validator result, X copy path, and
whether the operator clicked the post control.
